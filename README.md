# Cola B

Official site for Cola B — music, videos, stories, and the Aurora store.

Stack: Vite, TypeScript, React, Tailwind CSS, Supabase.

Live site: https://evilgloomy.github.io/colabbmusic/

## Development

```sh
npm install --legacy-peer-deps
npm run dev
```

GitHub Pages deploys from `main` via the existing Pages workflow.
